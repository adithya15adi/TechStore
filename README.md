# TechStore — Django E-commerce Website

## Project Overview
TechStore is a dynamic e-commerce website developed using Python and Django, inspired by modern electronics stores.

## Features
- Dynamic homepage with banner management
- Product listing and category filtering
- Product details with images, descriptions and prices
- User registration, login and logout
- Protected user account page
- Django admin panel for managing products, categories, banners and users
- Active/inactive controls for products and banners

## Technologies Used
- Python
- Django
- HTML and CSS
- SQLite (local development database)
- Pillow for image handling

## Run Locally
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Run `python manage.py migrate`.
5. Create an administrator using `python manage.py createsuperuser`.
6. Start the server using `python manage.py runserver`.

Open `http://127.0.0.1:8000/` in your browser.
